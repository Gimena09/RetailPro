# RetailPro

RetailPro es un proyecto de análisis de ventas de productos tecnológicos. La base de datos contiene información sobre categorías, clientes, productos y ventas.

El proyecto permite analizar la facturación, la cantidad de pedidos, el ticket promedio, los productos con mayor facturación y los clientes que realizaron más de una compra. También incluye consultas que relacionan las diferentes tablas de la base de datos.

## Herramientas utilizadas

- SQL: creación de la base de datos y realización de consultas.
- Power BI: visualización y presentación de la información.
- GitHub: almacenamiento y documentación de los archivos del proyecto.

## Archivos del repositorio

- `ventas_tech_db.sql`: crea la base de datos, las tablas y los registros utilizados en el proyecto.
- `m4_consultas_negocios.sql`: contiene las consultas de análisis comercial.
- `m5_consultas_joins.sql`: contiene consultas que relacionan las tablas mediante diferentes tipos de JOIN.

## Cómo ejecutar los scripts SQL

1. Abrir una herramienta compatible con SQL.
2. Ejecutar primero el archivo `ventas_tech_db.sql` para crear la base de datos, las tablas y sus registros.
3. Ejecutar `m4_consultas_negocios.sql` para obtener los resultados del análisis comercial.
4. Ejecutar `m5_consultas_joins.sql` para consultar la información relacionada entre las tablas.
5. Revisar los resultados obtenidos antes de utilizarlos en el análisis o en Power BI.
